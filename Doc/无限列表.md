# 无限列表

## 概述
  - 一种列表内容显示容器
  - 特点：当元素数量无限多时，只会显示行x列的刚好大于屏幕元素容量上限的物体
  通过拖动时的移动量，对滑动到超出屏幕的元素进行 移动到元素底部 并更新为元素底部之后元素内容的特征

## 构成
- 至少需要一个计算当前拖动位置的变量，用于计算当元素的基准位置 也就是屏幕顶端冗余后的卡牌位置后，如果拖动量累计大于顶部荣誉 paddingTop+cardRect.width时，意味着已经超出了屏幕的可视范围，则需要将超出部分的元素 ，移动到底部，并更新为后续的索引的元素 

- 拖动量的统计 MoveDelta;

## 接口   
- Create 
    - 用于接收数据并创建牌库数据备份
    - 遍历创建独立的各个CardPile
- 反序列化 
    - 接收CardDeck 
    - 赋值给对应变量
- 抽牌 
    - 接收要抽取List<Card>
    - 移除抽牌堆的对应牌 
    - 呼叫UI同步
- 弃牌 接收要弃掉List<Card> 
    - 这些牌没有其他结算，会进入弃牌堆 
    - 呼叫UI同步
- 洗牌
    - 打乱牌堆内数据的顺序
    - 非必需 洗牌动画
